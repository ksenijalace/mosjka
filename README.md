# The Hardest Kindness

A calm guide for dog owners deciding whether it is time to say goodbye, and for
the guilt and grief after euthanasia. Made in memory of Mosjka.

A single static page (`index.html`) with no build step and no server. Everything
a visitor writes (daily log, quality-of-life scores, letters) stays in their own
browser's `localStorage`, with a downloadable JSON backup.

To publish: Settings → Pages → Deploy from a branch → `main` / root.
